NT FactoSuite API · CFDI 4.0 SAT

Integra facturación electrónica
en minutos

API REST para emisión, cancelación y validación de comprobantes fiscales en México. Autenticación JWT, webhooks y soporte para Opera PMS, SAP, Oracle y cualquier ERP.

Paso 01

Autenticarse

Obtén tu JWT con POST /auth/token usando tu API Key de sandbox.

Paso 02

Emitir comprobante

Llama /cfdi/emitir con los datos del emisor, receptor y conceptos.

Paso 03

Recibir webhook

Configura tu URL en POST /webhooks para recibir eventos en tiempo real.
