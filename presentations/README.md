# Presentaciones — Next Technologies

Esta carpeta contiene presentaciones HTML para clientes y prospectos.

## Estructura
```
presentations/
├── _template/              ← plantilla base (NO modificar directamente)
└── [cliente-fecha]/        ← una carpeta por presentación
    ├── index.html          ← abrir en navegador para ver
    ├── assets/
    └── README.md
```

## Cómo crear una presentación
Dile al agente:
> *"Crea una presentación para [nombre del cliente] en [país], mostrando [productos]"*

## Cómo abrir una presentación
1. Ve a la carpeta de la presentación
2. Abre `index.html` con Chrome o Safari
3. Para navegar: flechas del teclado o clic en pantalla

## Cómo enviar al cliente
1. Comprime la carpeta como `.zip`
2. Envía por correo o WeTransfer
3. El cliente la abre sin instalar nada

## Convención de nombres de carpeta
`[cliente]-[año]-[mes]`
- Ejemplo: `hotel-camino-real-2025-04`
- Ejemplo: `grupo-bafar-2025-05`
