# Clientes NT Technologies

Esta carpeta contiene la información de clientes y prospectos.

## Estructura por cliente
```
clients/
└── [nombre-cliente]/
    ├── logo.png        ← logo oficial del cliente
    └── info.md         ← datos: país, industria, productos NT contratados
```

## Cómo agregar un cliente
Dile al agente: *"Agrega al cliente [nombre] de [país]"*
O crea la carpeta manualmente siguiendo la estructura de `_ejemplo-cliente/`.

## Convención de nombres de carpeta
- Minúsculas, sin acentos, con guiones
- ✅ `hotel-camino-real`
- ✅ `grupo-bafar`
- ❌ `Hotel Camino Real`
- ❌ `GrupoBafar`
