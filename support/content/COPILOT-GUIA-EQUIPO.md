# 🤖 Cómo usar GitHub Copilot — Guía para el Equipo Comercial

> No necesitas saber programación. Solo necesitas seguir esta guía.

---

## ¿Qué es GitHub Copilot?

Es tu asistente de inteligencia artificial personal. Lo abres desde la terminal de tu computadora y le pides lo que necesitas **en español**, como si le mandaras un mensaje de WhatsApp a un colega técnico.

---

## Instalación (una sola vez)

### 1. Instalar Copilot CLI

Abre la **Terminal** de tu Mac (`Cmd + Espacio` → escribe "Terminal") y pega este comando:

```bash
curl -fsSL https://gh.io/copilot-install | bash
```

Presiona Enter y espera a que termine.

### 2. Iniciar sesión en GitHub

```bash
copilot
```

La primera vez te pedirá iniciar sesión. Escribe `/login` y sigue las instrucciones en pantalla.

## ¿Y si no sé cómo pedir algo?

Solo escríbelo como puedas. Por ejemplo:

```
No sé cómo decirlo pero quiero que el sitio se vea más moderno
```

```
El cliente me dijo que el formulario no funciona en el sitio de México
```

El agente entenderá y te hará preguntas si necesita más información.

---

## Comandos útiles del agente

| Comando | Qué hace |
|---|---|
| `/skills` | Ver todas las capacidades disponibles |
| `/help` | Ver ayuda general |
| `Ctrl + C` | Cancelar lo que el agente está haciendo |
| `Ctrl + C` dos veces | Salir del agente |

---

## ⚠️ Cosas importantes

- El agente **siempre confirma antes de hacer cambios importantes**. Si no estás seguro, di "no" o "cancela".
- Si algo salió mal, avísale al CIO — todo se puede revertir.
- **Nunca compartas** contraseñas ni datos sensibles con el agente.
- Los cambios en los sitios se aplican automáticamente en unos minutos.
