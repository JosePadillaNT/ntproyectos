# Skills — Agente NT Landing Pages

Las skills son capacidades especializadas del agente Copilot para este proyecto.
El equipo comercial las activa de forma natural con sus solicitudes.

## Skills disponibles

| Skill | Se activa cuando pides... |
|---|---|
| `site-change` | Cambiar algo en un sitio web |
| `new-presentation` | Crear una presentación para un cliente |
| `new-country` | Crear el sitio de un nuevo país |
| `new-client` | Registrar un nuevo cliente |
| `site-audit` | Revisar el estado del sitio |
